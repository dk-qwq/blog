##### 晚饭
	WKL他爸请客，我又和WKL讨论题，看到JSK自测出来了就到他家测T1，我才9/10，想了一下，果然是r-l<n-1的情况炸了
```cpp
#include<bits/stdc++.h>
using namespace std;
int main()
{

	freopen("candy.in","r",stdin);
	freopen("candy.out","w",stdout);
	int n,l,r,ans;
	cin>>n>>l>>r;
	ans=r%n;
	ans=max(ans,l%n);
	if(l+n-1<=r) {
		ans=max(ans,n-1);
	}
	cout<<ans;
}
```
	把最后if里的l改成l/n*n就10/10了。。真的吐了，现在已经准备退役了
